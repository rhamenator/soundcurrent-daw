GPL-3.0-only. Generated deterministic test signals; no user music/microphone or
physical audio capture. The ZIP retains original32 raw prefixes/journals from
observation37, lane/clock mapping, independent sample analysis, original logs and
failure receipts33–40, plus original owned route details from38. It contains
no executable/installer. It is an evidence corpus, not a complete loadable project.

delay across all24179 samples. Other31 lanes match the common expected origin.
A later successful repeat does not replace these originals. Cause remains unproven
because original37 route metadata was not retained. Original38 has a13.88ms
predominantly-CPU callback overrun and a sink clock gap before injection.
