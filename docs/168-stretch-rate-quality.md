## Actual workflow and results

Generate original stereo float32 sine fixtures: 1,000 Hz at amplitude 1.8 and
1,500 Hz at amplitude −1.35. Each source has `2*rate+1` frames, deliberately
exercising nonintegral output length at half and three-halves duration ratios.
Use the existing isolated v4 worker, integer source origin, no added context,
formant preservation off, and unchanged pinned R3/copy processor identities.

Analysis uses the largest central power-of-two window no longer than half the
render. Frequency targets derive independently from the original carrier and
pitch ratio; the estimator searches ±12% around that target. Original and exact
unity observations characterize estimator bias. These windows and these pure
tones do not establish event timing, attacks, phase-preserving microphone groups,
formants, mixed music or listening quality. Q-STRETCH and Q-PITCH remain open.

## Original refusal and corrected harness

The parent artifact verifier creates a fresh project identity on every invocation.
The first harness used one project root per sample rate. Its second 48 kHz
invocation correctly refused to overwrite the earlier project, with
`Refusing to overwrite another project`. That refusal stays in the original
bank's process record and original summary: three passes and one failure.

Harness correction `8058778` gives each parent workflow a distinct owned project
root. A separate retry copied the already completed failing case's raw audio,
derivative, intent and completion marker into a new root. Original input bytes
remained unchanged. The unchanged verifier passed 7,919 assertions, including
zero callback allocation/free/lock audit counts and the shared waveform/persistence
checks. No DSP was rerun, and the original bank is not relabeled to the new runner.
Future executions of the corrected runner use isolated roots from the outset.

## Resource use, retention and limits

Configure and build the two existing targets with two jobs, nice 10 and ionice
class 2/level 7. Each worker has a 256 MiB ceiling and ten-second processing
deadline; observation has a fifteen-second deadline. The bank has a 240-second
deadline and a 128 MiB owned-file limit. Local generated data occupies about
55 MiB including the retry. No disk-filling exercise, package install, VM,
physical audio route, playback interruption or equalizer modification occurred.

[Compact retained observations](../tests/results/M2/2026-10-11-stretch-rate-quality/README.md)
bind 309 actual Git source inputs, runner/contract/executable hashes, configure/
build logs, all original outcomes/measurements and the separate retry. The
41,114-byte public archive includes text/JSON only. Complete generated PCM stays
local and can be regenerated by the committed runner. The public verifier audits
source/protocol/report arithmetic; it cannot recompute spectra from hashes.
NumPy 2.3.5 is an existing local analysis tool, not a new shipping dependency.

Native Windows, installation, listening, larger shifts, additional rates/channel
layouts, transient/group phase and complete Q-STRETCH/Q-PITCH acceptance remain
required. Full M2–M11/X004/X005, all-Europe translation/review/UI coverage and
separate functional/quality/content/native-project goals remain incomplete.
