# ADR107: Integrate the explicit protected mode without promoting general quality

2026-10-10 UTC. Status: next implementation selected; prototype is opt-in only.

Checkpoint148 implements the original protected planner and actual R3 gap
processing. Annotated synthetic attack timing and full-core preservation improve
over the previous scheduler. Sustained gaps still change relative phase;
background-bed onset ambiguity and listening remain unresolved. Full P008/P011/
P012 and frozen F/Q/C/N gates remain unchanged.

Next implement one vertical, versioned integration slice:

1. Original stable user marker IDs and exact raw/output coordinates in owned
   project state. Persist protection sizes, explicit real-source halo policy,
   processor/channel/chunk identity and normalized derived boundaries. Preserve
   schema1.14 constant/region state semantics through an explicit migration.
2. A separately versioned supervised worker request/cache key and verified
   derivative: validate source identity, all admitted coordinates, processor
   policy, exact duration, complete output and source/gap provenance. Unsupported
   fractional acoustic coordinates refuse; do not silently quantize.
3. An experimental transient-protected selection and one editable marker with
   preview/review/Apply. Rejection or worker failure keeps the original clip and
   marker state unchanged. Do not detect fixture names or repair measured peaks.
4. Undo/Redo, save/reopen, crop/split/seek and shared playback/offline export using
   the verified prepared derivative. Credit/ownership retirement and recovery
   must remain outside callbacks, with exact source and stable marker identity.
5. Native Windows worker/state tests, Linux/Windows UI qualification and installed
   recovery before delivering that workflow in a preview. No product release
   upload is authorized by source-backup publication alone.

Mark the mode's current acoustic scope explicitly. Grouped phase-preserving
material must refuse any unsupported quality-mode request, rather than equating
channel count, cancellation or copied-core passes with phase preservation.
Spacing64 is geometric admission, not measured processing-quality coverage;
other rates/spacing/channel layouts need evidence before acoustic claims.
General material, automatic transient analysis, sustained-group processing,
tempo maps and pitch/formants remain planned work. Do not spend another milestone
shopping default algorithms or improving geometry alone before the usable
vertical slice. Future quality improvements may replace the gap processor under
a new identity while preserving original markers and raw takes.
