# ADR 151: admit existing rendered comp handles by source coordinates

Status: accepted for already prepared artifacts; missing-span generation remains open.

The identical-asset guard rejected valid derivatives with admitted samples. Use the
validated source relationship and exact inverse maps to compare their proposed
window with the retained take's physical source interval. A retained processed
take supplies its own inverse map. Preserve every existing asset, anchor, setting,
context, key and source identity; extend geometry/fades in one ordinary transaction.
Keep original same-asset bounds and all session validation intact.

Promote the existing exact warp addition rather than duplicate arithmetic. Refuse
overflow and missing spans. This introduces no new schema or processor and does
not authenticate a fabricated model as actual audio. Actual completion/audio
verification remains mandatory in render admission and prepared playback.

An asynchronous extension will require separately reviewable planning/admission
without bypassing ApplyClipStretch's ordinary raw-anchor guard. That is required
remaining work, not waived by this prepared-artifact correction.
