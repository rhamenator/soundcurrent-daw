# ADR-044: Native desktop punch audit and rendered control readiness

Date: 2026-10-06. Status: accepted bounded fixture design; product parity open.

Forward an optional native clock observer through existing worker-prepared audit
options to qualify the production desktop recording path. Leave normal operation
unobserved by default, use fixed callback storage and verify journals/output only
after native/disk owners join. Keep device origins independent of musical
attachment coordinates and preserve underlying clips in grouped Undo/Redo.

Canonical selection acknowledgement does not establish that the Qt inspector has
rendered its new geometry. Before fixture screenshots/mouse interactions, wait
for the expected inspector and settle scrolling within a bounded interval. Retain
the original failed visibility observation without assigning an unrecorded cause;
do not change production geometry based solely on that fixture failure.

Require complete native timing/cycle coverage and exact sample/state evidence.
Short owned-route success does not promote sustained/physical/Windows or frozen
reference acceptance contracts.
